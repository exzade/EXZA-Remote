# Security policy

EXZA Remote takes reports of potential security problems seriously.

## Reporting a vulnerability

**Please do not disclose suspected vulnerabilities in public GitHub issues, discussions, or pull requests.** Email **info@exza.de** with a concise description, affected URL or component, impact, and safe reproduction steps. Avoid attaching live credentials, access tokens, customer data, or destructive proof-of-concept material.

If you believe an account or device connection is compromised, disconnect/revoke it through the customer portal and review your account and AI-client authorizations.

## Scope

The GitHub repository is a **public documentation and marketing repository only**. It does not contain the EXZA Remote server, agent, or private MCP plugin source code. This policy is not a commitment to any particular response time, public bug bounty, or formal certification.

For general troubleshooting rather than vulnerabilities, use [EXZA Help](https://remote.exza.de/help).
