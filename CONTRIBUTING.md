# Documentation contributions

Thank you for helping improve EXZA Remote documentation.

This is a **public information repository**, not the development repository for the proprietary EXZA Remote source code.

You may propose corrections to public documentation, translations, broken links, or feature-description clarity through an issue or pull request. Do not post credentials, customer details, pairing codes, private logs, infrastructure files, or copied proprietary software.

Please use the official [Help Center](https://remote.exza.de/help) for account-specific support and [private security contact](SECURITY.md) for vulnerabilities. Submission of documentation suggestions does not create a license to the underlying EXZA Remote software.
