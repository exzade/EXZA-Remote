# EXZA Remote — public introduction

**Published: November 2026**

**EXZA Remote is a remote MCP connection platform for people who want ChatGPT, Claude, or another compatible AI assistant to work with their own computer while retaining explicit control over permissions.**

Rather than paste terminal output and file listings into a chat, you can pair an authorized computer through an EXZA account and use supported MCP tools for permitted local workflows.

## Who is it for?

- Developers who want to inspect a project and run reviewed commands with an AI assistant.
- Technical users who need read-only system checks, diagnostics, or process information.
- Makers who want permission-aware interactions with supported desktop or command-line tools.
- Anyone who wants a clear device list, pairing process, and revocable access in one portal.

## What's available?

- A public website and customer dashboard.
- Account-based pairing with a six-digit terminal code and local confirmation.
- A remote MCP HTTPS endpoint with OAuth.
- A client setup path for macOS, Windows, and Linux, with OS-dependent capabilities.
- 59 registered MCP tool interfaces — **not** a claim of universal support or unrestricted access.
- A free tier advertising 10,000 successful tool calls per EXZA account per UTC month.

The product is proprietary. This GitHub repository is a public product and documentation hub, **not** a download of private source code.

## Try it

1. [Visit EXZA Remote](https://remote.exza.de/).

3. [Follow the installation guide](GETTING_STARTED.md).
