## One-line description

**EXZA Remote connects ChatGPT, Claude, and compatible AI assistants to your computer with device pairing and user-controlled permissions.**

## Short description

EXZA Remote helps users connect AI assistants to their own computers using the Model Context Protocol (MCP). Pair a computer through a web dashboard, authorize your chosen AI client, and use supported file, terminal, system, and desktop tools with appropriate permissions and local approval controls.

## Medium description

Your computer. Your control. EXZA Remote bridges compatible AI assistants such as ChatGPT and Claude with a user-owned macOS, Windows, or Linux computer. An EXZA account and a paired local client provide a route to supported file inspection, terminal workflows, process checks, and selected desktop actions. User permissions, device scope, and sensitive-operation approvals remain part of the workflow. The platform offers a free tier with 10,000 successful tool calls per EXZA account each UTC month and a web dashboard for devices and usage.

## Positioning

- **What it is:** A remote MCP connection and workflow platform with explicit device and action controls.
- **Who it is for:** Developers, AI power users, technical teams, and people who want AI assistance with authorized local tasks.
- **What makes it different:** One EXZA account, paired devices, a web portal, and permission-aware computer tools across supported AI clients.
- **What not to claim:** Official OpenAI/Anthropic affiliation; universal 59-tool compatibility on every OS; unrestricted automatic remote access; independently certified security; guaranteed platform/plan availability.

## Suggested introduction (technical community)

We built EXZA Remote to let compatible AI assistants work with a computer you own, without treating every request as unlimited permission.
